THREE.JS CONCEPT — Mesh = Geometry + Material
A Mesh is not a self-contained object: it holds a reference to a BufferGeometry (the shape, stored as typed arrays on the GPU) and a Material (the shader + parameters). They are independent and reusable — one geometry can be shared across 1,000 meshes with no extra GPU memory.
ANIMATION CONCEPT — Delta time
cube.rotation.y += speed × delta — multiplying by delta (seconds since last frame) makes the rotation rate frame-rate-independent. At 30 fps delta ≈ 0.033 s; at 120 fps delta ≈ 0.008 s. The cube completes the same angle per second on every device. Never animate by a fixed amount per frame.
THREE.JS CONCEPT — devicePixelRatio
renderer.setPixelRatio(window.devicePixelRatio) scales the drawing buffer by the screen's DPR (2 on Retina, 3 on some phones). Without it the GPU renders at CSS pixel resolution and the browser stretches the image — it looks blurry on HiDPI screens. For performance-critical scenes, cap at 2: Math.min(window.devicePixelRatio, 2).
THREE.JS CONCEPT — Shadow map pipeline
Enabling shadows requires five steps: renderer.shadowMap.enabled, choose shadowMap.type, set light.castShadow, set mesh.castShadow, set mesh.receiveShadow. Each shadow-casting light triggers an extra render pass of the entire scene from the light's viewpoint. Limit shadow-casting lights to one or two for real-time performance.
