ANIMATION CONCEPT — Pivot-based orbit
The Earth doesn't move in a circle by code — the pivot (Object3D at the Sun's origin) rotates: earthPivot.rotation.y += orbitSpeed * delta. The Earth mesh is offset from the pivot by position.x = 5. When the pivot rotates, the Earth sweeps a perfect circle — no trigonometry needed. This is how every game engine drives orbital or wheel motion.
THREE.JS CONCEPT — World vs local position
The Moon's position.x is 1.6 — relative to its pivot, which is relative to the Earth, which is relative to the Sun. moon.getWorldPosition(v) computes the full accumulated transform: world = Scene × earthPivot × earthMesh × moonPivot × moonMesh. That's the number shown in the top-right readout.
ANIMATION CONCEPT — Tidal locking
Enable "Tidal lock": the Moon's self-rotation speed is locked to its orbital speed. One face always points at the Earth — exactly as the real Moon behaves. This demonstrates that tidal locking is simply self-rotation = orbit speed in the parent's frame. Toggle it off to see the difference immediately.
THREE.JS CONCEPT — Object3D hierarchy
Object3D is the base class for everything in Three.js: Mesh, Light, Camera, Group. A pure Object3D (the pivot) has no geometry or material — it's an invisible transform node. The same pattern is used in Unity (empty GameObject), Unreal (SceneComponent), and Blender (empty object parenting) to build any hierarchical articulated structure.
