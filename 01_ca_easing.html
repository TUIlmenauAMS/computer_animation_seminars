1. Easing & Animation Curves

Demo 1 showed how keyframes store values at discrete times and how linear interpolation fills the gaps. But linear interpolation produces motion at constant speed — and in the real world, almost nothing moves at constant speed. Objects accelerate as they start and decelerate as they stop. This quality is what makes motion feel alive.

An easing function is a mapping from a linear progress value t ∈ [0, 1] to a non-linear output e ∈ [0, 1]. Instead of moving at a fixed rate, the animated value follows the shape of that curve. The same principle drives CSS transitions, game-engine tweens, and professional animation software.

The most expressive easing functions are cubic Bézier curves, defined by two control points P1 and P2. The CSS transition-timing-function property and After Effects graph editor both use exactly this model. The live curve plot below shows the easing curve in real time — watch the moving dot to see exactly where on the curve the animation currently is.

Core idea: Easing is the difference between motion that looks right and motion that looks mechanical. An easing function remaps the linear progress t ∈ [0,1] to a non-linear output e ∈ [0,1]. The same easing function is used in CSS transitions, game engines, and professional animation software.

3. How It Works

The WebGL scene (Steps 1–5) is the same sphere and ground plane from Demo 1 — the shaders, geometry builders, and mat4 helpers are carried over unchanged. The new material is in Steps 6–8.

Step 6 defines the easing functions as pure JavaScript functions f(t) → e where both input and output live in [0, 1]. The cubic Bézier is implemented as a factory: given the two control points, it returns a closure that uses Newton's method to invert the Bézier x-component and then evaluates the y-component. Step 7 wires all the controls, including the pointer-drag logic on the 2D canvas for moving P1 and P2. Step 8 is the render loop: it drives a ping-pong timer, applies the current easing function, and redraws both the WebGL canvas and the curve plot every frame.

The curve plot is drawn with the Canvas 2D API (not WebGL). Each frame it samples the active easing function at 200 equally-spaced points and draws a polyline. The moving dot is plotted at the current t value. In cubic Bézier mode the two control-point handles are drawn as draggable circles.

Connection to other tools: After Effects uses the same cubic Bézier model in its graph editor. The CSS function cubic-bezier(x1, y1, x2, y2) takes exactly these four parameters. GSAP's named eases (e.g. power2.inOut) compile to the same math. The cubic-bezier.com tool is the interactive reference used by web developers worldwide.
