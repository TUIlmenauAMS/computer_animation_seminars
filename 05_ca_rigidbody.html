Demo 1: First Rapier Scene

A Rapier physics world runs in parallel with the Three.js scene. Boxes fall under gravity, stack on a ground plane, and collide with each other — all computed by Rapier's rigid body solver. Click anywhere on the ground to throw a new box from the camera toward that point.

Read the source code of this file as a tutorial. Every line is commented with numbered STEP blocks that map each Rapier concept — world creation, rigid body, collider, world.step(), and sync to Three.js — to the matching Three.js mesh. Open DevTools → Console to see body counts and timestep logs.

ANIMATION CONCEPT — The physics loop vs the render loop
A physics engine runs at a fixed timestep (60 Hz here) that is independent of the render frame rate. The fixed timestep accumulator pattern solves this: each frame, real elapsed time is accumulated; fixed physics steps consume it in 1/60 s chunks. If your machine runs at 30 fps, the accumulator fires two physics steps per render frame. If it runs at 120 fps, it may fire zero (and re-render the last physics state). This guarantees the simulation is deterministic and reproducible regardless of hardware.
RAPIER CONCEPT — RigidBody + Collider are always separate
A RigidBody holds mass, velocity, and position. A Collider defines the shape used for collision detection. You attach one or more colliders to a body after creating both. This separation lets you use a cheap convex shape (cuboid, ball, capsule) for physics while rendering a detailed mesh — the collider and the visual mesh never need to match exactly, only approximately.
ANIMATION CONCEPT — Three.js is only the display layer
Rapier owns the ground-truth position and orientation of every body. syncPhysicsToRender() copies body.translation() → mesh.position and body.rotation() → mesh.quaternion every frame, after world.step() completes. The Three.js meshes have no physics knowledge — they are purely visual puppets driven by Rapier's state. This same pattern applies to every physics engine integration, not just Rapier.
